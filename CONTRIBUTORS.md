## Attribution policy

Older generated or refactored source headers used the generic label `Author: Helpdesk Team`. That label does not accurately describe file-level authorship.

Where a file needs an attribution note, the project uses:

```text
Authorship: See CONTRIBUTORS.md and repository history
```

This preserves credit without replacing Git's per-commit contribution record with a broad collective-author label.

This document records repository contribution history. It does not determine legal copyright ownership, work-for-hire status, or rights arising from any employment agreement.
